# Quanto Vale Il Tuo GitHub?

> Codebase della campagna di sensibilizzazione rivolta alle aziende italiane.

---

## Il problema

Le aziende italiane investono in brand, marketing e design — ma ignorano completamente come appaiono agli occhi dei developer e della comunità open source.

Eppure un profilo GitHub aziendale è una vetrina pubblica: racconta come si lavora, che qualità ha il codice, se si partecipa alla comunità, se ci si può fidare di quel team.

**Un GitHub trascurato non è neutro. Costa.**  
Costa in recruiting, in partnership, in credibilità tecnica, in fiducia.

---

## L'obiettivo della campagna

Questa campagna vuole far capire alle aziende italiane che **l'immagine tecnica conta quanto il logo**.

La presenza su GitHub — repository pubblici, contribuzioni open source, documentazione, attività della community — è oggi un segnale forte che developer, CTO, investitori e partner leggono prima ancora di fissare una call.

Il messaggio è semplice: **il tuo GitHub ti fa guadagnare o ti fa perdere opportunità?**

---
